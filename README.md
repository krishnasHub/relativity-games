# Relativity Games

Small browser games about special and general relativity, with the physics computed for real.

- **[Proper Time](proper-time/)**: fly a relativistic courier from the cockpit. You see real Doppler shifts, aberration, beaming and time dilation, all the way up to the cosmic microwave background glowing in front of you.

Each game is one HTML file with no build step. Open it directly, or serve the folder.

Tests: `node proper-time/tests/verify-physics.js` and `node proper-time/tests/verify-levels.js`.
